진행 상황 및 결과 재정리 · 2026-11-12

목차·표·그림 배치와 서술 형식은 pilot_progress_report.docx를 참고했다. 실험 내용과 수치는 pixel_sensitivity 프로젝트에서 실제 완료·검증한 결과만 사용했다. 참고 파일의 실험 수치·설정·해석은 옮기지 않았다.

요약

3개 데이터셋과 3개 학습 시드에 대한 주 모델 9개를 평가했다. 추가 학습7개와 모델·조건27개 평가 조합을 완료했으며, 각 평가는8×8위치·10개 배치를 사용했다.

시드11에서 화소 수1→9→25가 증가할수록 평균 Recall 감소가 커졌고, 같은25개에서 부분 강도는 완전 치환보다 손실이 작았다.

밝은25개 조건의 3학습 시드 평균 Recall 감소는 GC10 0.049±0.087%p, NEU 0.814±0.236%p, 새 PCB 2.118±0.378%p였다. ±는 시드 간 표본 표준편차이며 신뢰구간이 아니다.

GC10은 Recall 감소와 최대 위치가 학습 시드에 따라 안정적으로 재현되지 않았다. NEU와 PCB는 세 모델 모두 평균 Recall이 감소했고, PCB는 세 모델 모두 G37이 최대였다.

새 PCB 시드11의 공동 위치 밴드에서는 G28·G29·G36·G37이 전체 위치 평균보다 손실이 컸다. 제품 결함 노출과의 순위상관은0.889였으며, 이 연관을 센서 고유 좌표의 인과 효과로 해석하지 않는다.

2. 실험 설정

2.1 공통 모델과 평가 절차

모델은 객체 탐지용 YOLOv8n이다. 동일한 원본 COCO 사전학습 가중치에서 데이터셋별로 독립 학습했다. imgsz640, 최대100epoch, patience20, AdamW(lr0=0.001), 학습 batch16, deterministic=True를 사용했다.

학습 시드11·22·33을 비교했다. 공간·색상 증강은 모두0으로 고정했고, 화소 손상을 넣지 않은 자료로 학습했다. 검증 자료의 최적 체크포인트를 고른 뒤 모델을 고정해 시험했다.

손상은 원본 해상도의 uint8 RGB 배열에 넣은 뒤 동일한 YOLO 전처리를 통과한다. 한 번의 추론에는 8×8 중 한 칸에만 주입한다. 같은 배치를64칸으로 옮겨 평가하며,10개 배치를 사용한다.

유형·수·강도·군집의7조건 비교는 학습 시드11에서 수행했다. 학습 시드22·33은 주 조건인 밝은25개·분산에서 반복했다. 모든 유형을3시드로 전수 교차한 실험은 아니다.

그림5. 새PCB의 관찰 손실·기술적 기준모형·잔차. 기준모형은 위치 셀 번호를 사용하지 않았다. 공통 색상 범위이며 인과 보정 결과가 아니다.

겹침·노출과 강하게 연결되지만, 밝기·제품 구조·정답 상자의 여유 영역·모델 의사결정 경계 등 측정하지 않은 구성 요인이 남는다. 잔차가 있다는 것만으로 센서 고유 좌표 효과가 입증되는 것은 아니다.

7.1 공통 한계

손상은 처리된RGB영상의 유사 화소 이상이다. 실제RAW센서·demosaic·ISP·DPC·온도·노출 의존 고장을 검증하지 않았다.

원본 해상도와resize배율이 다르다. GC10은축소, NEU·PCB는확대되므로 같은25개가 같은 손상 비율이나 모델 입력상의 면적을 뜻하지 않는다.

PCB숫자ID분할은 대리 그룹 분리이며 실제 물리 보드·로트 독립성은 미확인이다. GC10파일명A+B그룹과NEU이미지ID도 실제코일·제품 독립성을 보장하지 않는다.

현재 주 분석은 제품 결함 객체 단위이다. 제품 단위 출하 미검출률·정상제품 오거부율·카메라 수명 또는 교체비를 측정하지 않았다.

같은 이미지와GT가 여러 위치·배치에 반복된다. 관측행 수를 독립 표본 수로 해석하지 않고 그룹·배치 공동 재표집과 별도 학습 반복을 구분했다.

조건 비교·분포 진단은 탐색에 사용한 자료의 추가 분석이다. 독립 확증 실험이나 모든 비교를 통합한 전체 오류율 보장으로 표현하지 않는다.

9. 정리 및 산출물

현재 합의한 범위의 추가 검증은 완료됐다. 보고서의 주장은 입력영상·검사 모델·현재 데이터 분할에 조건부인 화소 손상 민감도로 한정한다. 강한PCB중앙 손실은 반복 모델에서도 관찰되지만, 제품 결함 노출 구성을 센서 좌표 자체의 취약성과 혼동하지 않는 것이 핵심이다.

GC10에서 낮은 평균 Recall변화를 곧바로 무영향으로 판정하거나, 시드11의 작은 감소만으로 모든 모델의 일관된 저하를 주장하지 않는다. NEU·PCB의 반복된 평균 감소와 자료별 유형·배치 차이를 함께 제시한다.
